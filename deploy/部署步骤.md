# 部署操作手册（Task 2 + Task 3）

所有 `<...>` 都要换成你自己的值。不要把 API Key、ACR 密码、Basic Auth 密码写进报告或 Git。

## Task 2：ECS + ACR

### 0. 控制台准备
1. ECS 控制台 → 实例 → 记下 **公网 IPv4**、系统（建议 Ubuntu 22.04/24.04）、规格（x86 = amd64，倚天/ARM = arm64）。
2. ACR 控制台 → 个人版实例 → 创建命名空间 `<namespace>`、仓库 `ai-learning-assistant`（本地仓库，私有）→ 设置“访问凭证”密码。
   仓库页面会显示登录地址，例如 `crpi-xxxx.cn-hangzhou.personal.cr.aliyuncs.com`。
   **ECS 与 ACR 同地域时**可用 VPC 地址拉取，更快且免流量费。

### 1. 本机构建并推送（Mac 是 arm64，ECS 通常是 amd64，必须指定平台）
```bash
ACR_REGISTRY=<登录地址> ACR_NAMESPACE=<namespace> ECS_ARCH=amd64 bash deploy/build-and-push.sh
```

### 2. 复制文件到 ECS 并启动
```bash
scp deploy/compose.ecs.yml root@<ECS_IP>:~/ai-agent/compose.yml   # 先在 ECS 上 mkdir -p ~/ai-agent
scp deploy/ecs-setup.sh deploy/ecs-record-check.sh deploy/nginx-ai-agent.conf deploy/ecs-domain-setup.sh root@<ECS_IP>:~/ai-agent/
ssh root@<ECS_IP>
cd ~/ai-agent
AILA_IMAGE=<登录地址>/<namespace>/ai-learning-assistant:v1 bash ecs-setup.sh
```

### 3. 安全组
ECS → 安全组 → 入方向 → 添加：TCP 14242，授权对象 `<你的公网IP>/32`（百度搜“IP”可查）。

### 4. 证据
- 浏览器打开 `http://<ECS_IP>:14242/ui/`，截图（带地址栏）。
- 在 ECS 上：`bash ecs-record-check.sh`，输入公网 IP → 生成 `ecs-docker-check.txt`，确认 `Website URL check: PASS`。
- 下载回本机：`scp root@<ECS_IP>:~/ai-agent/ecs-docker-check.txt .`

> 如果 ECS 自己访问自己的公网 IP 失败（安全组只放了你的 IP），临时再加一条授权对象为 ECS 公网 IP/32 的 14242 规则。

## Task 3：域名 + HTTPS + Basic Auth

1. 云解析 DNS → 你的域名 → 添加记录：类型 `A`，主机记录 `ai`，记录值 `<ECS_IP>`。
   本机验证：`dig +short ai.<你的域名>` 返回 ECS IP。
   注意：中国内地 ECS 上用域名对外提供网站需要 **ICP 备案**；没备案时 80/443 会被拦截，可改用中国香港等境外地域的 ECS。
2. 安全组入方向添加 TCP 80、443，授权对象 `0.0.0.0/0`。
3. ECS 上：
   ```bash
   cd ~/ai-agent
   DOMAIN=ai.<你的域名> AUTH_USER=<用户名> bash ecs-domain-setup.sh
   ```
   脚本会安装 Nginx/Certbot、创建 Basic Auth 用户（提示输入密码）、申请证书，最后打印：未认证 `401`，认证后 `200`。
4. 证据截图：
   - 浏览器打开 `https://ai.<你的域名>/ui/` 弹出登录框（未认证被拦截）；
   - 点“取消”后显示 401 页面；
   - 输入账号后进入界面（带地址栏和小锁）。
5. 收紧端口：把 `~/ai-agent/compose.yml` 的端口改为 `"127.0.0.1:14242:14242"`，然后
   ```bash
   sudo docker compose -p ai-learning-assistant up -d
   sudo docker ps            # 应显示 127.0.0.1:14242->14242/tcp
   ```
   安全组删除 14242 入站规则，再次确认 HTTPS 正常、`http://<ECS_IP>:14242/ui/` 已无法访问。
   （ecs-docker-check.txt 要在这一步**之前**生成。）
